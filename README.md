# שכר לימוד

אפליקציית PWA לניהול שכר לימוד בישיבה — תלמידים, תשלומים, פריסה שנתית
ודשבורד גבייה. עברית מלאה, RTL, מובייל ודסקטופ.

**כתובת האפליקציה** — `android.url` שבתצורה.

## הפעלה ראשונה

1. הריצו מול פרויקט ה-Supabase (`supabase.url` שבתצורה), דרך ה-SQL Editor,
   את `hanhala-ruchanit/migrations/000_schema.sql` ואז את `migrations/000_schema.sql` —
   הבעלים ראשון, והרצה חוזרת אינה משנה דבר.
2. צרו את המשתמש הראשון **ידנית** ב-SQL Editor — ⛔ אין משתמש ברירת מחדל ואין
   סיסמה בריפו. הטביעה נגזרת בקונסולה של הדף עצמו:
   `(await import('./core/auth.js')).authMakePassFp('<שש ספרות>')` מחזירה
   `{salt, fp}`, והם נכנסים ל-`pass_salt` ול-`pass_fp` של שורה ב-`sl_users`,
   עם `role` שהוא `'admin'`.
3. ⛔ אין מסך התקנה באפליקציה — ההתקנה נעשית מול המסד, מקובץ
   הסכימה, ולא מתוך הדף.

## מסכים

- **דשבורד** — גבייה בפועל מול יעד, פר-חודש, עם גרף וקו יעד.
- **תלמידים** — כרטיס תלמיד עם פריסה שנתית, טווח הצטרפות/עזיבה ויתרת זכות.
- **יומן תשלומים** — רישום תנועות, עריכה ומחיקה רכה.
- **הגדרות** — תלמידים, סעיפים ורשימות, ואזור המצב (סנכרון · מידע טכני).

## פיתוח

הכל בקובץ אחד: `index.html`. אין build.

```bash
node tools/guard.mjs       # שומר הדחיפה — חובה לפני כל push
```
