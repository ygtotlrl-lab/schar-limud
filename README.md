# שכר לימוד

אפליקציית PWA לניהול שכר לימוד בישיבה — תלמידים, תשלומים, פריסה שנתית
ודשבורד גבייה. עברית מלאה, RTL, מובייל ודסקטופ.

**כתובת האפליקציה** — `android.url` שבתצורה.

## הפעלה ראשונה

1. הריצו מול פרויקט ה-Supabase (`supabase.url` שבתצורה), דרך ה-SQL Editor,
   את `hanhala-ruchanit/migrations/000_schema.sql` ואז את `migrations/000_schema.sql` —
   הבעלים ראשון, והרצה חוזרת אינה משנה דבר.
2. ⛔ אין מסך התקנה באפליקציה — ההתקנה נעשית מול המסד, מקובץ
   הסכימה, ולא מתוך הדף.

## מסכים

- **דשבורד** — גבייה בפועל מול יעד, פר-חודש, עם גרף וקו יעד.
- **תלמידים** — כל הכרטיסים ברשימה אחת לפי שיעור (א׳ · ב׳ · ג׳) ומחזור, וסימון «טופל» לחודש; ארכיון לפי מחזור; ניהול — הוספה ומעבר שנתי; כרטיס תלמיד עם פריסה שנתית, תקופות פעילות ויתרת זכות.
- **יומן תשלומים** — רישום תנועות, עריכה ומחיקה רכה.
- **הגדרות** — שכר לימוד ברירת מחדל, אמצעי תשלום, ואזור המצב (סנכרון · מידע טכני).

## פיתוח

הקליפה ב-`index.html`, והקוד ב-`app/` וב-`core/` — מודולים שהדפדפן טוען כמות שהם. אין build.

```bash
node tools/guard.mjs       # שומר הדחיפה — חובה לפני כל push
```
